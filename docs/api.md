# Invexo API Documentation

This document describes the API routing, versioning strategy, and endpoint catalog implemented in the Invexo backend.

---

## 1. Versioning & Legacy Compatibility

To support the Next.js client seamlessly without breaking existing queries, the backend uses a dual-routing compatibility layer in [main.py](file:///c:/Users/Lakshya%20Hindocha/OneDrive/Desktop/Invexo/backend/app/main.py):

* **Modern Versioned Prefix**: All endpoints are fully registered under `/api/v1/` (e.g., `/api/v1/auth/login`).
* **Client Fallback (Legacy Routing)**: The same API router is also mounted at the root (`/`) to resolve non-prefixed client calls (e.g., `/auth/login`, `/search`, `/news/general`).

## 2. Authentication Endpoints

## 3. Stock & News Endpoints

### Stock Search
* `GET /api/v1/search?q={query}`
  * Searches stock indices by ticker symbol or name. Supports SQLite and PostgreSQL syntax fallbacks.

### Stock & Technical Indicators
* `GET /api/v1/market/stock/{symbol}`
  * Fetches historical stock price data, indicators (RSI, MACD, SMA), and returns technical signals. Cached in Redis for 1 hour.
* `GET /api/v1/market/index/{symbol}`
  * Fetches index level details.

### News Sentiment
* `GET /api/v1/news/general`
  * Fetches general Indian market financial news. Cached for 4 hours.
* `GET /api/v1/news/general/search?q={query}`
  * Searches market news.
* `GET /api/v1/news/general/suggest`
  * Gets suggested trending news.
* `GET /api/v1/news/{symbol}`
  * Returns company-specific news sentiment analysis. Cached in Redis for 4 hours.

## 4. AI Predictions & Advisor Endpoints

### ML Predictions (XGBoost + SHAP)
* `GET /api/v1/predict/daily-picks`
  * Returns top daily stock picks generated by ML models. Cached for 24 hours.
* `GET /api/v1/predict/{symbol}`
  * Performs live XGBoost price trend forecasting and returns local SHAP feature explanations.

### AI Financial Advisor (Requires Premium/Admin Roles)
* `GET /api/v1/advisor/recommendations?goal={goal}&budget={budget}`
  * Returns customized asset allocations based on risk levels and horizons.
* `POST /api/v1/advisor/recommend`
  * Payload-based recommendations request.
* `POST /api/v1/advisor/calculate`
  * Calculates compound returns adjusted for inflation.
* `POST /api/v1/advisor/portfolio-summary`
  * Calculates portfolio-level metrics and returns future projections.
